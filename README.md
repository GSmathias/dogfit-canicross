# DOGFIT CANICROSS — Site

Primeira versão da Home em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — página inicial
- `css/style.css` — identidade visual e responsividade
- `js/script.js` — menu mobile, WhatsApp e ano automático
- `assets/` — imagens, logos e vídeos

## Antes de publicar

1. Troque o número de exemplo em `js/script.js` pelo WhatsApp oficial da DOGFIT (DDI + DDD + número).
2. Substitua os blocos “FOTO...” pelas imagens reais.
3. Atualize os dados do próximo evento.
4. Adicione a logo oficial em `assets/logos/`.
5. Teste o site em celular e computador.

## Publicação

O projeto foi organizado para versionamento no GitHub e publicação no Cloudflare Pages.
